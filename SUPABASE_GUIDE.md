# Supabase Setup Guide

To get the Guestbook working, follow these steps:

1. **Create a Supabase Project**: Go to [supabase.com](https://supabase.com) and create a new project.
2. **Get API Keys**:
    - Go to **Project Settings** -> **API**.
    - Copy your `Project URL` and `anon public` key.
    - Paste them into your `.env.local` file.
3. **Create the Guestbook Table**:
    - Go to the **SQL Editor** in Supabase.
    - Run the following SQL:

    ```sql
    create table guestbook (
      id bigint generated by default as identity primary key,
      created_at timestamp with time zone default timezone('utc'::text, now()) not null,
      name text not null,
      message text not null
    );

    -- Enable Realtime for this table
    alter publication supabase_realtime add table guestbook;

    -- Enable Row Level Security (RLS)
    alter table guestbook enable row level security;

    -- Create policy to allow anyone to read
    create policy "Anyone can read guestbook"
    on guestbook for select
    to anon
    using (true);

    -- Create policy to allow anyone to insert
    create policy "Anyone can insert into guestbook"
    on guestbook for insert
    to anon
    with check (true);
    ```

4. **Redeploy**: Ensure your environment variables are set in Vercel or your hosting provider.
