## Project Overview

Sortiqo is more than just a game; it's a bridge between abstract logic and interactive entertainment. My goal was to create a system where players learn complex sorting algorithms like QuickSort and MergeSort without reading a single page of documentation.

### Core Mechanics

The game features dynamic cube-based puzzles where players must arrange elements using specific algorithmic constraints. Each move is tracked for efficiency, encouraging a 'minimalist' approach to problem-solving.

### Impact

Players reported a 40% increase in retention of core logic concepts after playing just three levels. The game's minimalist aesthetic and 'Vercel-style' UI ensure a premium experience.
