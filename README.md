# Snehal Fulluke - Personal Portfolio

A premium, production-grade personal developer portfolio website inspired by parthh.in.

## Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Backend**: [Supabase](https://supabase.com/) (Guestbook)
- **Content**: [MDX](https://mdxjs.com/)

## Features

- **Hero Section**: High-impact landing with animated typography and glow effects.
- **Projects**: Interactive project showcase with sorting and hover effects.
- **Photography**: Responsive gallery grid with cinematic light-box preview.
- **Guestbook**: Real-time messaging system powered by Supabase.
- **Blog**: SEO-optimized MDX blog system.
- **Responsive**: Fully optimized for mobile, tablet, and desktop.
- **Dark Mode**: Sleek dark-first aesthetic.

## Getting Started

### 1. Project Setup

```bash
npm install
```

### 2. Environment Variables

Create a `.env.local` file in the root directory:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 3. Supabase Setup

Follow the [SUPABASE_GUIDE.md](./SUPABASE_GUIDE.md) to set up your guestbook table and policies.

### 4. Run Locally

```bash
npm run dev
```

### 5. Deployment

This project is optimized for [Vercel](https://vercel.com/).

1. Push to GitHub.
2. Link to Vercel.
3. Add Environment Variables.
4. Deploy!
